# Cloud Computing Lab Project

## Overview
This project demonstrates cloud computing concepts using Docker, Kubernetes, PyTorch, GPU computing, and monitoring.

## Components

### Component 5: Kubernetes
Deployment using Minikube and service exposure.

### Component 6: PyTorch
Linear model training and prediction.

### Component 7: GPGPU
CUDA-based GPU execution using Google Colab.

### Component 8: CUDA-X
Mixed precision and quantization.

### Component 9: Inference
Model inference and server-style execution.

### Component 10: Monitoring
Kubernetes resource monitoring and deployment.

## Tools Used
- Docker
- Kubernetes (Minikube)
- PyTorch
- Google Colab
